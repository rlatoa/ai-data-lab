MISSION 02

IQR로 승선 요금 이상치 찾기

Q1은 1사분위수, Q3은 3사분위수입니다. 아래 기준을 보고 이상치라고 생각하는 값을 모두 선택하세요.

하한 = Q1 − 1.5 × IQR상한 = Q3 + 1.5 × IQR

이 표본의 Q1 = 10, Q3 = 30, IQR = 20 → 정상 범위: -20 ~ 60

Fare(승선 요금) 상자그림

COLAB CODE
q1 = titanic['Fare'].quantile(0.25)
q3 = titanic['Fare'].quantile(0.75)
iqr = q3 - q1
lower = q1 - 1.5 * iqr
upper = q3 + 1.5 * iqr
titanic[(titanic['Fare'] < lower) | (titanic['Fare'] > upper)]

ONE-MINUTE REVIEW

1분 정리

  • 데이터 전처리는 결측치와 이상치를 처리해 분석에 적합한 형태로 가공하는 과정입니다.
  • IQR은 Q3−Q1이며, 일반적으로 Q1−1.5×IQR보다 작거나 Q3+1.5×IQR보다 큰 값을 이상치로 봅니다.
  • 핵심 속성은 문제 해결에 꼭 필요한 속성으로, 히트맵과 상관계수 등을 활용해 탐색할 수 있습니다.
