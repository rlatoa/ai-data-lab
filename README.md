# 데이터 실험실

2022 개정 교육과정 고등학교 **인공지능 기초** 2단원 중 `데이터 전처리와 핵심 속성 추출` 실습을 돕는 정적 웹사이트입니다.

## 제공하는 실습

- 타이태닉 데이터로 결측치 처리 방법 비교
- IQR 기준으로 승선 요금 이상치 판별
- 붓꽃 데이터 히트맵으로 핵심 속성 추출
- Google Colab용 예제 코드 복사
- 브라우저에 학습 진행 상황 저장
- Pyodide 기반 브라우저 Python·pandas 코드 실행
- CSV 업로드 후 `head()`, `shape`, `isna()` 결과 확인
- 학생이 직접 작성한 pandas 코드로 결측치·이상치·상관관계 분석

## GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 선택하면 `.github/workflows/pages.yml`이 사이트를 배포합니다.
